# Quick Guide: Property Value & Current Price

## The 3 Questions Users Always Ask

### Q1: "I updated purchase price but current value didn't change - why?"

**Answer**: The current value comes from a different source:

| Source | Priority | Used When | Updated |
|--------|----------|-----------|---------|
| Manual Override | 1st | You set a custom value | When you click "Update Value" |
| System Estimate | 2nd | Market data is available | Periodically by system |
| Purchase Price | 3rd | No other data | Never (locked at purchase) |

**Action**: The system uses the best available market data. If you want your own value, click "Update Value" and set a manual override.

---

### Q2: "Why is my property value going down?"

**Answer**: Market conditions have changed since you bought it.

```
Bought: Oct 2014 - ₹45,57,871 (your investment then)
Today:  Current Market - ₹32,74,275 (what similar properties sell for NOW)
Change: -28.1% (market correction over 10 years)
```

**This is normal** because:
- Market cycles happen (up and down)
- 10 years is a long time in real estate
- Valuations reflect current market, not historical purchase price
- Every property experiences cycles

---

### Q3: "How do I update the current value?"

**Answer**: Three options:

#### Option A: Set Manual Override
1. Click **"Update Value"** button
2. Check box: "Enter your property's current value"
3. Type your estimate (e.g., 45,00,000)
4. Click **"Save Override"**
5. System uses this value for ALL calculations

#### Option B: Let System Calculate
- No action needed
- System updates periodically with market data
- Estimates based on comparable properties

#### Option C: Clear Override
1. Click **"Update Value"** button
2. Uncheck: "Enter your property's current value"
3. Click **"Clear Override"**
4. System reverts to market-based estimate

---

## Current Value Priority (Memorize This!)

```
IF your_manual_override_exists:
  use your_manual_override  ← Highest priority (YOU win!)
ELSE IF system_estimate_available:
  use system_estimate  ← Market data
ELSE:
  use purchase_price  ← Fallback only
```

## Why Your Numbers Make Sense

### Your Property Example
```
Purchase Price:        ₹45,57,871 (Oct 2014)
System Estimate:       ₹32,74,275 (current market)
Your Manual Override:  [Not set yet]

Current Value Used:    ₹32,74,275 (system estimate)
Unrealized Gain/Loss:  -₹12,83,596 (vs purchase price)
```

### What This Means
- You paid ₹45,57,871 in 2014
- Market says similar properties are worth ₹32,74,275 today
- But YOUR property's real value depends on:
  - ✅ Rental income you receive
  - ✅ Loan you're paying
  - ✅ Expenses you pay
  - ❌ NOT just the absolute price

## The Real Metric: XIRR

**Current Value** tells you: "What would I get if I sold today?"

**XIRR tells you**: "What's my actual annual return as an investor?"

```
XIRR = The annual percentage return that accounts for:
  + Initial investment
  + Rental income collected
  - Loan EMI paid
  - Expenses paid
  + Current property value
  = Your true financial return
```

**This is what actually matters!**

## Checklist: Understand Your Property

- [ ] Know your **Purchase Price** (locked - won't change)
- [ ] Know your **Current Value** (can be manual override or system estimate)
- [ ] Know your **XIRR** (your real annual return)
- [ ] Know your **Rental Income** (monthly cash coming in)
- [ ] Know your **Expenses** (monthly cash going out)
- [ ] Know your **Loan Status** (how much equity is yours)
- [ ] Set **Manual Override** if you have better market data

## When to Set Manual Override

**DO set override if**:
- You got a professional valuation (engineer/surveyor)
- You negotiated a recent sale
- You have recent comparable property sales data
- You believe market estimate is significantly wrong

**DON'T set override if**:
- You're just guessing
- You want to inflate your net worth
- You haven't researched the market

**System knows best if**:
- You have no recent market data
- You haven't been tracking comparable properties
- You haven't sold similar properties recently

---

## Common Mistakes to Avoid

❌ **Mistake 1**: Assuming lower current value = you lost money
- This ignores rental income and loans
- Check your XIRR instead

❌ **Mistake 2**: Not updating when you have better data
- If you got a valuation, use "Update Value"
- Manual override takes priority

❌ **Mistake 3**: Comparing purchase price to current price directly
- That's 10 years of market changes
- XIRR is the fair comparison

❌ **Mistake 4**: Ignoring cash flow
- Current value is just one part of your return
- Rental income can mean positive returns despite price decline

## Updates & Recalculation

### When Does System Estimate Update?
- Periodically (system runs updates)
- When market data changes
- When comparable properties sell nearby
- Check "Property Details" for last update date

### Your Manual Override
- Persists until you clear it
- Applies to all calculations (XIRR, returns, etc.)
- You can update anytime

### Historical Data
- Purchase price never changes (locked at purchase)
- Historical system estimates stored for trends
- Visible in "Value vs Purchase Price" chart
