# WealthLens Instagram Campaign Skill

When invoked via `/campaign`, help generate Instagram Reel content for WealthLens.

## Product Context
- **Product:** WealthLens — AI-powered portfolio management tool
- **Target audience:** Busy Indian professionals (25–45) who don't actively manage their wealth
- **Tone:** Calm, smart, trustworthy friend — NOT a finance bro or hard-seller
- **USP:** AI nudges + portfolio health score + asset allocation visibility

## Positioning Statement
> "Your wealth is working harder than you — but only if you're watching it right."

## Content Pillars (rotate in order)
1. **Did You Know?** (30%) — surprising wealth/finance data points that stop the scroll
2. **Mini Explainer** (30%) — one concept explained simply in under 45 seconds
3. **Tool Spotlight** (20%) — one WealthLens feature, shown via screen record, no hard sell
4. **Myth-Buster** (20%) — debunk common bad financial advice

## Reel Script Format
Always produce scripts in this structure:

[0–3s] HOOK — bold statement or uncomfortable truth (text on screen + voiceover)
[3–25s] INSIGHT — the core value, keep it simple, one idea only
[25–35s] PROOF/DEMO — personal anecdote or quick app screen record
[35–45s] CTA — follow, save, or link in bio (rotate between these)


## When User Says `/campaign new reel`
Ask:
1. Which pillar? (Did You Know / Explainer / Tool Spotlight / Myth-Buster)
2. Topic or leave it to me?
3. Tone this week: data-heavy or story-driven?

Then produce:
- Full voiceover script (timestamped)
- On-screen text suggestions
- Caption with hook line
- 3–5 hashtags

## When User Says `/campaign schedule`
Produce a 4-week content calendar in a markdown table:
- Week number, Day, Pillar, Topic, Hook line

## When User Says `/campaign review [script]`
Review a provided script for:
- Hook strength (would it stop a scroll in 1.5s?)
- Clarity (could a 10-year-old understand it?)
- CTA clarity
- Alignment with brand tone
Give a score /10 and 3 specific improvement suggestions.
